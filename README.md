One original line, at most 200 characters, roasting a gadget or app used every day. `main.py` writes the entry text to `/output/entry.txt` (deterministic, mode 0644).

The line: *"My banking app texts a login code to my phone, which is locked until I enter the code my banking app just texted."*

Why it should win: a fresh angle nobody else roasts — the circular login loop — with a concrete detail everyone with a banking app recognises instantly, in one tight sentence.
